# loan-default-prediction_capstone_project
Loan default prediction project combining EDA, machine learning models (Gradient Boosting, XGBoost), and business insights via Power BI.
## Project Overview
Loan defaults pose significant risks to financial institutions, affecting profitability and sustainability.  
This project analyzes loan disbursement patterns, identifies customer segments most likely to default, and builds machine learning models to predict defaults before they happen.  
The final Gradient Boosting model was deployed as a decision-support tool, while Power BI dashboards translated technical results into actionable business insights for stakeholders.

## Project Highlights
- Built a loan default prediction system end-to-end

- Performed data cleaning, EDA, feature engineering & model optimisation

- Trained Machine Learning models & selected the best using evaluation metrics

- Hyperparameter-tuned Gradient Boosting model

- Deployed model on Streamlit for real-time predictions

## Project Workflow
- Data Preprocessing & EDA

Cleaned missing values & outliers

## Model Development
Model	Purpose
Logistic Regression	Baseline model
Decision Tree	Simple tree model & interpretability
Random Forest	Ensemble method for improved accuracy & feature importance
LightGBM	Gradient boosting algorithm optimized for speed & performance (selected after evaluation)
AdaBoost	Boosting model to improve weak learners
XGBoost	Robust boosted trees, handles complex patterns well
Gradient Boosting	Best-performing model 

Evaluation Metrics

Accuracy

Precision

Recall

F1-Score
LightGBM achieved best performance with balanced accuracy & recall for default prediction.
