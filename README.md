# loan-default-prediction_capstone_project
Loan default prediction project combining EDA, machine learning models (Gradient Boosting, XGBoost), and business insights via Power BI.
## Project Overview
Loan defaults pose significant risks to financial institutions, affecting profitability and sustainability.  
This project analyzes loan disbursement patterns, identifies customer segments most likely to default, and builds machine learning models to predict defaults before they happen.  
The final Gradient Boosting model was deployed as a decision-support tool, while Power BI dashboards translated technical results into actionable business insights for stakeholders.

## Project Workflow
1. Data Preprocessing & EDA (Python, pandas, matplotlib, seaborn)
2. Machine Learning Model Building (Logistic Regression, Random Forest, XGBoost, Gradient Boosting)
3. Model Evaluation (Accuracy, Precision, Recall, F1-score, ROC-AUC)
4. Deployment-ready Gradient Boosting model (hyperparameter tuned)
5. Visualization (Python plots & Power BI dashboards)
